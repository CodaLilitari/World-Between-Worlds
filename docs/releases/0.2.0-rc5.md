# World Between Worlds 0.2.0-rc5

An experimental recipe-book converter for bringing reviewed **Jedi Knight:
Dark Forces II** levels and selected mods into **Mysteries of the Sith**, using
your own games and original downloads. This candidate packages the completed
development checkpoint; it does not complete the 150-entry Massassi expansion.

## Included in this candidate

- **53 recipe records, 52 selectable:** nine stock multiplayer maps, 32 custom
  multiplayer entries (some containing several worlds), five singleplayer
  entries and six optional mod prototypes. Castle Conflict is the additional
  unavailable record. Status labels and per-entry limits remain visible.
- **MLP3:** all eight authored worlds and their cycle, with exact original
  contributors and notice retained. Initial JK/MotS comparisons cover all eight;
  Subway and Hoodwink also have 45-second passive observations in each mode.
- **Imperial Siege On Derra IV:** a reproducible singleplayer prototype with
  narrowly preserved original missing resources, native MotS compatibility
  bindings and an explicit missing-pilot warning. Original and converted opening
  renders and 45-second passive observations passed; the mission is unqualified.
- Earlier development additions include Canyon Stream, Steal the Bottle and
  separately selected skin-mod prototypes. Ninja Kage 7.0 remains optional in
  **Mods**; no conversion automatically installs or loads another mod.
- Versioned output archives, embedded per-recipe provenance, read-only installed
  conversion scanning, and source-pinned ownership/omission checks. No shared
  global dump of retail resources is generated.
- The updater now names `CodaLilitari/World-Between-Worlds`. Existing packages
  pinned to the former publisher require a fresh install to switch publisher;
  their trusted repository is not silently redirected.

## Download and use

Use the Windows x64 standalone ZIP, Linux x86-64 standalone ZIP, or portable
Python source ZIP accompanying this candidate. Standalone packages bundle Python
and the native folder chooser. Source use requires Python 3.10 or newer; optional
Tkinter enables Browse, and paths can also be entered manually. The updater
manifest records the Linux build's actual minimum glibc version.

Extract the program into its own folder, open it, choose your JK and MotS roots,
then explicitly select the desired levels or mods and their original downloads.
Conversions go to a separate output folder. Follow each result's README for the
correct OpenJKDF2 MotS episode and any required startup profile.

**The CodaLilitari GitHub account is currently restricted. Live release publishing
and automatic update delivery are unconfirmed.** Repository visibility and local
package checks do not establish that GitHub can serve updates. An existing local
copy can run offline; `--no-update` skips the network check. A GitHub draft, if
created, is a prepared candidate rather than a public automatic update.

## Test scope and remaining work

The included metadata distinguishes independent structural verification, opening
renders, passive simulation, authored gameplay and peer synchronization. Neither
an available recipe nor a successful host load establishes a full playthrough or
multiplayer parity. See the [checkpoint](../top50/WAVE3_CHECKPOINT.md),
[Imperial Siege evidence](../top50/IMPERIAL_SIEGE_REVIEW.md) and per-entry reviews.
The [release validation record](0.2.0-rc5-validation.json) binds all three
packages and their checksums. Windows and Linux each passed 433 source tests
with two environment-specific skips. Both exact standalone executables passed
version, normal launcher readiness and local interface/catalog checks with
updates and browser opening disabled. Those checks did not exercise the native
file chooser or run a game. The Linux package requires glibc 2.35 or newer.

Within the frozen 50 MP / 50 SP / 50 mod queue, 40 entries have exact-input
recipes, 39 are selectable and 110 still lack recipes. Chaos Eternal remains
unbuilt and unregistered: its isolated Force-profile implementation and exact
AI-template omission review are saved for later work. Dark Emperor 2 intake is
also pending. The stock JK campaign is a separate future plan preserving both
story routes with neutral MotS Force powers.

Gameplay still needs targeted doors/lifts, pickups and respawn, AI/combat,
objectives and saves, endings and map transitions, audible effects, all authored
mod appearances and matched second-peer checks. Imperial Siege's missing AT-ST
pilot branch is source-predicted behavior, not an executed test. Castle's engine
prerequisite is not delivered by this converter. Al's large skin roster tests
used the separate engine's model/sound capacity fixes; this release bundles no
engine binary and does not certify every skin or stock engine build.

The model/sound corrections are retained in the separate
[OpenJKDF2-MotS-Fixes fork](https://github.com/CodaLilitari/OpenJKDF2-MotS-Fixes/commit/69028bf3088c9e3e3a83bc0cbb96cfb816c5acd8).
They are not included in WBW's updater package or submitted upstream here.

## Credits and asset boundary

Original tooling by **Andrei Pemberton, with Coda Lilitari in Astra Codex**.
Original level and mod authors retain their credits and notices; sources are
listed in [the original-download document](../../SUPPORTED_CUSTOM_SOURCES.txt)
and the frozen Massassi inventories. The name evokes the Star Wars paths between
times and places, here connecting two games and their community-created worlds.

Packages contain original tooling, recipes, UI artwork and runtime license
notices. They contain **no retail assets, community game/mod assets, original
downloads, completed conversions or engine executable**. The user supplies the
exact originals; WBW extracts only the selected recipe's required resources
locally. The MIT license covers our software and documentation and grants no
right to redistribute generated game assets. See [NOTICE](../../NOTICE.md).
