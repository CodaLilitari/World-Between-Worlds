# World Between Worlds 0.2.0-rc6

This experimental release makes CTF setup explicit and supplies portable
application packages. It retains RC5's 53 recipe records, 52 selectable; it does
not complete the remaining Massassi expansion or add unreviewed custom CTF maps.

## Changes

- **Required CTF mod is visible:** the picker, library, queue, Details and completed
  results explain the required support mod. WBW generates `bridge-ctf-ui` from
  owned MotS data for the three stock CTF maps; all players must install/load it
  at startup using `-motsCompat -path bridge-ctf-ui`.
- **Explicit native-menu titles:** all three stock CTF episodes now start
  `CTF -`. Their recipe revisions advance to `wbw_v2`, allowing Scan MotS folder
  to identify older conversions. No other game payload member changes from RC5.
- **Custom CTF follows the same rule:** notices apply by reviewed gameplay type,
  not stock/custom category. Different custom systems need their own reviewed
  mod instructions; the stock dependency is not silently imposed on them.
- **Historical research:** hedge's April 1998 port and Marc Sauvé's 1999 derivative
  were located and compared. The old JKLs zero 573 nonzero surface extra-light
  values; WBW's actual outputs preserve them and the original corner intensities.

See the [CTF review and screenshots](../validation/CTF_REVIEW_2026-09-25.md) for
sources, exact runtime identities, custom-map counterexamples and limitations.

## Download

- **Windows 11 x64:** `World-Between-Worlds-0.2.0-rc6-windows-x86_64.zip` —
  extract into its own folder and run **WBW.exe**. Python and the native folder
  chooser are included; no separate installation is needed.
- **Linux x86-64:** `World-Between-Worlds-0.2.0-rc6-linux-x86_64.zip` —
  extract and run `./WBW`; requires glibc 2.35+ and a desktop for the chooser.
- **Source:** `World-Between-Worlds-0.2.0-rc6-source.zip` — Python 3.10+.
- `SHA256SUMS.txt` and `wbw-release.json` accompany these exact packages.

**The CodaLilitari account restriction may prevent anonymous downloads and
automatic update delivery.** Authenticated release/asset checks do not prove
public access. Once downloaded, WBW runs offline; use `--no-update` to skip its
network check. Older packages pinned to the previous repository owner require
a fresh install to switch the update source.

## Validation and limits

Windows and Linux each ran **437 source tests: 435 passed, two platform-specific
skips**. **53 UI tests** and **22 maintainer tests** passed. The source ZIP rebuilt
byte-identically. Both standalone binaries passed version, hidden startup,
loopback health/catalog and UI-byte checks, with updates/browser opening disabled.
Embedded contents matched the same frozen source and passed the asset scan.
Exact digests are recorded in [release validation](0.2.0-rc6-validation.json).

Fresh native-menu tests selected all three explicit CTF titles. Separate
30-second production hosts loaded each actual revision-2 filename in MotS mode,
with correct red/gold descriptors and live CTF team rules. Tests used documented,
pinned existing engine binaries; they were not rebuilds of current engine HEAD.
Flag lifecycle, scoring, a connected second player and retail parity remain
outside this check. The preserved native ysalamiri inventory item is not removed
globally; the incorrect red-flag HUD binding is corrected by the support mod.
