# World Between Worlds 0.2.0-rc7 — portfolio updates

RC7 moves automatic update discovery and package downloads to the public
portfolio. Users no longer depend on GitHub API access for the normal update
check. **RC6 and earlier require one manual RC7 download** to change that policy.
Portable Windows 11 x64, Linux x86-64 (glibc 2.35+) and Python 3.10+ source
packages use the same feed and retain package verification and startup fallback.

The portfolio entry also includes a real workbench UI screenshot alongside the
existing original-JK/converted-MotS game captures. Interface artwork is decorative;
those screenshots do not establish new gameplay compatibility.

The catalog remains 53 records / 52 selectable. Existing map payload revisions
are unchanged. The September 27 development checkpoint adds exact Chaos Eternal
source gates and a Dark Emperor II review; both remain unregistered. Chaos's
complete pack still rejects three differing comment-rewritten shared resources.
No new game runs, CTF scoring, campaign playthrough or multiplayer parity are
claimed for RC7. See [the checkpoint](../top50/CHECKPOINT_2026-09-27.md) and
[RC6's scope](0.2.0-rc6.md).

WBW remains an asset-free recipe-book converter. Users supply owned games and
reviewed original downloads; game assets and finished conversions remain local.
Approved documentation screenshots are separate from distributable game assets.

See [the user guide](../../packaging/USER_GUIDE.md) for migration and
[the publishing contract](../PORTFOLIO_UPDATES.md) for feed maintenance.
