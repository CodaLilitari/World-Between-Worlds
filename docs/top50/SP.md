## First three source reviews

**The Phantom Menace: Final Battle (Revised)** has one episode row and one JKL. Its authored Obi-Wan model, allied Qui-Gon, Maul combat scripts, timed intro and ending sequences must survive conversion. The original readme already reports falling-boss/ally cases that can break messages or completion; those must remain identified as source defects rather than falsely attributed to the conversion. Native MotS uses saber ordinal 11 / descriptor 131, while the original grant uses JK bin 10. The original rank-six, 300-mana initialization matches native MotS SP regeneration: both regenerate rank/2 per second and cap at rank*50. Native MotS uses a separate SP bin-69 sentinel, so the MP maximum-mana fix must not be copied into this SP recipe. These are review findings, not completed gameplay validation.

**Imperial Siege On Derra IV** has one large JKL, including 2,006 sectors and a declared capacity of 322 COG instances. Preserving actors, authored objectives and the complete combat/cutscene graph is essential. Its readme forbids using the level as a base for additional levels and permits original distribution with the notice intact. WBW publishes only its own tooling and source-locked instructions, keeps the original notice, and does not present local compatibility conversion as permission to redistribute modified level assets.

**Dark Emperor 2: The Last of the Jedi** contains two GOBs and thirteen JKLs. Its episode has eleven rows with an authored branch and source CD fields; the extra GOB is explicitly required as a startup overlay by the installation instructions. A first-map-only result would be an incomplete package. Every JKL, episode transition, branch, progression grant, authored startup resource, and generated cutscene must be accounted for. The original author permits building additional levels and requests credit; that does not change WBW's no-asset-redistribution rule.

## Source packaging findings

All 50 official source ZIPs were captured. Forty-nine contain captured original notices; **Yun and Kyle vs. the Darkjedi** contains no standalone readme in the downloaded ZIP. Twelve packages need manual structure review before conversion: several use installers, some GOBs contain duplicate or unsafe paths, one ZIP has a corrupt screenshot member, and **The Valley Battle** appears to be an overlay of an existing world rather than a new JKL.

Raw directory checks distinguish identical duplicates from competing content. A Jedi's Discovery 1/2/3 and The Fall of JuzSoft include byte-identical duplicate entries. Sith Lord Discotech and Freedman Threat include differing bytes under duplicate paths. Any normalization needs an exact recipe operation and source pin; WBW's general archive parser remains strict.

Imperial Siege's preliminary original-resource closure has seven unresolved filenames. These include an actually used material and sound references, not just unused preload rows. The missing `14awscrn.mat` exists in native MotS and may support an explicit native binding after review; other missing sound names require individual source decisions. They are recorded in the machine-readable inventory and are not silently filled or waived.

## Required SP implementation gates

- Preserve the complete TYPE 1 episode table, entry IDs, ordering, branch destinations, referenced worlds and cinematics. Validate every world, including authored extra/test worlds retained in the package.
- Preserve objectives, AI decisions, damage/death behavior, doors/elevators, custom actors, player identity and authored cutscenes. SP is not a renamed multiplayer conversion.
- Map only proven semantic incompatibilities in weapon ordinals, descriptors, Force limits and native bindings. Review each numeric argument in context; do not blanket-rewrite inventory numbers.
- Resolve only needed retail dependencies from the supplied owned games. Native SP templates and startup state must be checked directly; MP K1 templates are not an automatic SP substitute.
- Keep startup overlays explicit and scoped to the episode. Retain exact original readmes and source hashes in local receipts.
- Rebuild deterministically, independently validate structural preservation and exact changes, then exercise startup, save/load, death/restart, combat, cutscenes and every progression branch in the engine before claiming those behaviors work.

The standalone SP adapter now provides a source-locked experimental recipe for the complete **Phantom Menace: Final Battle** episode. It preserves the original episode bytes, all placed actors and COG arguments, geometry and physics, authored strings, and source resource transformations. Its only gameplay edits are the three counted saber descriptor/ordinal corrections described above. Native SP resource/template dependencies are computed from the pinned native inputs and checked independently; arbitrary extra native assets and native replacements are rejected.

The pilot rebuilds byte-for-byte, and all 16 contract/payload tests passed using local owned inputs. Deliberate script/model removal, authored health and physics changes, progression changes, wrong thing templates, missing native preloads, altered capacities and extra/overridden native assets were rejected. The exact output SHA-256 is `e046f5546ca20a555da32fa897d12d220fb38a708c47f73f297e5f1083c9509f`.

A private 45-second headless load smoke on pinned OpenJKDF2 build `fd8ddfc23f09540068318bedcc3f08e5ce6b12ea5ee04ed3cf45fd8ed46b7873` confirmed MotS single-player mode, the selected TYPE 1 episode/world, a player, advancing simulation and no resource diagnostics. This does **not** validate rendered combat, ally/boss behavior, cutscene completion, objectives, death/restart, save/load or level completion. The recipe remains a prototype. A second complete episode now has an experimental recipe, described below; the other 48 entries remain a conversion work queue.

Run the asset-free contract tests with `python -m unittest test_sp_converter -v`. ## Second complete-episode prototype

**Legends of the Force: Darth Maul vs. Qui-Gon Jinn** (Massassi ID 26, BoBo Fett) now has an exact source-locked recipe. Its original Qui-Gon player model and health, double-saber Maul logic, antigravity behavior, ship landing cutscene, autosave call, complete episode row and Force grants remain intact. The recipe applies only two counted gameplay edits: the saber inventory grant and saber ordinal exclusion. Native SP pickup controllers are used after direct script review. Original notices and credits, including Hideki and Al MacDonald, are preserved in the local output.

The output hash is `4e09aa3b87ba79afdb7dea6b70149eba85813c3e789448ade2f9f83a9f62daae`. Whole-episode repeat builds match, and the combined SP suite passes 20 tests, including rejection of a changed Force rank, an altered sector sound and a native mana-controller injection. Sector sound references receive only the explicit filename mapping; numeric and topology fields must remain exact.

A 30-second smoke on the original pinned `fd8ddfc2...` runtime passed in MotS single-player mode with the correct world, advancing simulation and no resource diagnostics. Full combat, double-saber rendering, cutscene completion, autosave restoration and mission completion remain unverified.

Native MotS's SP Force-well script recalculates its maximum from rank on every pulse. The source rank-seven/current-mana-200 setup therefore retains a cap of 350 and regeneration of 3.5 per second. This differs from the cached multiplayer maximum. The engine also automatically translates ordinary weapon ordinals below 11 in `SetInv` and `ChangeInv`; no blanket numeric rewrite is applied.

For this recipe's additional local payload tests, set `WBW_SP_TEST_MAUL_ORIGINAL` to the exact reviewed `MaulJinn.zip`, alongside the owned baseline path.

## Exact resource-directory verification

The final SP verifier now checks recognized literal resource tokens against the
engine's actual full virtual paths, rather than accepting a matching basename
anywhere in an archive. Materials try `mat/` before `3do/mat/`; sounds try
`sound/` before `voice/`. Models use `3do/`, keys use `3do/key/`, and scripts use
`cog/`. Puppets, soundclasses, AI classes, colormaps, sprites and particles use
their respective `misc/pup/`, `misc/snd/`, `misc/ai/`, `misc/cmp/`, `misc/spr/`
and `misc/par/` directories. Directory fallback is evaluated before archive
precedence. The selected episode and pinned native MotS resource/sound archives
are the declared scope; the unmounted native singleplayer episode cannot fill
a missing dependency.

These paths come from the audited OpenJKDF2 loaders `sithMaterial_Load`,
`sithSound_FindInSearchPaths`, `sithModel_Load`, `sithKeyFrame_Load`,
`sithSoundClass_Load`, and the corresponding animation-class, AI-class,
colormap, sprite, particle and COG loaders. The check preserves complete tokens
and rejects qualified tokens containing directory separators until their
specific loading context has been reviewed. It does not infer a meaning from
the trailing filename or guess how a computed COG string will resolve.

The verification report records `wbw.sp-typed-literal-closure.v1`, counts of
per-file and distinct literals, and selected provider/directory counts. The
unchanged Phantom payload passes 2,110 per-file checks covering 1,437 distinct
literals; the unchanged Maul/Jinn payload passes 1,964 checks covering 1,369
distinct literals. Neither contains a qualified resource token. This is a
verification-only change, so both recipes remain revision 1; source locks and
receipts must be regenerated for the updated verifier.

Synthetic controls reject wrong-directory-only matches and qualified tokens,
and confirm material/sound fallback and its precedence. The SP suite now has
24 tests with both private fixtures enabled. Recognized literal closure does
not establish computed or extensionless references, live cache state, loose
files, external startup overlays, rendered appearance, or gameplay behavior.
